# シー買い物ナビ

2026年11月4日の東京ディズニーシーで買う予定の品を、買い方別・場所別にまとめたスマホ用の1ページです。

- 公開ページ: https://hakonikomoru.github.io/tds-shopping-navi/
- 販売場所・価格・画像は東京ディズニーリゾート公式サイト（2026年11月2日確認）より
- 依存なしの単一HTML。`index.html` をブラウザで開けばそのまま動きます

## 列とアプリの表示

商品カードと店舗一覧に、現地の待ち列・アプリ必要／任意／不要を表示。リストでは条件と購入済みを組み合わせて絞り込めます。待ち列は購入経路からの目安で、リアルタイム待ち時間ではありません。公式の販売条件は2026年11月2日確認、当日はアプリ・現地の最新案内を優先してください。

- ショップ3店: スタンバイパス。バッジ: アプリ限定配送。
- FSの3飲食店: モバイルオーダー。他の対象飲食店: アプリ任意。対象外店と掲載ワゴン: 店頭購入。
- 公式出典はサイトの「注意」タブに掲載。`GUIDANCE`、`PLACE_ACCESS`、`ACCESS` を更新して表示を保守します。
- 検証: `node tests/guidance.cjs`。HTMLの変更後はブラウザで絞り込み、購入済み保存、タブ・地図、狭い画面を確認します。

## クリスマスの装飾

深緑・赤・生成りの配色に、SVGのリース・ヒイラギと金のアクセントを使用。装飾は静止表示で追加画像の通信なし。列・アプリの意味を表すバッジは従来の色分けを保ちます。装飾用SVGは読み上げ対象から除外しています。
