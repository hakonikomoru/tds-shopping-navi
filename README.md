# シー買い物ナビ

2026年11月4日の東京ディズニーシーで買う予定の品を、買い方別・場所別にまとめたスマホ用の1ページです。

- 公開ページ: https://hakonikomoru.github.io/tds-shopping-navi/
- 販売場所・価格・画像は東京ディズニーリゾート公式サイト（2026年11月2日確認）より
- 依存なしの単一HTML。`index.html` をブラウザで開けばそのまま動きます

## 列とアプリの表示

商品カードと店舗一覧に、現地の待ち列・アプリ必要／任意／不要を表示。リストでは条件と購入済みを組み合わせて絞り込めます。待ち列は購入経路からの目安で、リアルタイム待ち時間ではありません。公式の販売条件は2026年11月2日確認、当日はアプリ・現地の最新案内を優先してください。

- ショップ3店: スタンバイパス。バッジ: アプリ限定配送。
- FSの3飲食店: モバイルオーダー。他の対象飲食店: アプリ任意。対象外店と掲載ワゴン: 店頭購入。
- 公式出典はサイトの「注意」タブに掲載。`GUIDANCE`、`PLACE_ACCESS`、`ACCESS` を更新して表示を保守します。
- 検証: `node tests/guidance.cjs`。HTMLの変更後はブラウザで絞り込み、購入済み保存、タブ・地図、狭い画面を確認します。

## 冬の装飾：ふんわりスノー

採用された「ふんわりスノー」の淡い水色・白を基調に、CSSの小さな雪だるま、雪の縁取り、SVGの雪の結晶を使用。装飾は静止表示で追加画像の通信なし。列・アプリの意味を表すバッジは従来の色分けを保ちます。装飾は読み上げ対象から除外しています。

## 店頭と配送の併売

チャーム・耐熱ガラスマグ・ファンキャップは、商品カード上に「店頭＋配送注文」と常時表示。「買い方」のアプリ欄にも一覧を掲載。フィギュアは店頭単品／配送BOXのみの違いを表示します。配送は入園後の公式アプリ注文で、ショップのパスは不要。予定数と購入済みチェックは購入方法にかかわらず共通です。


## 見送りの商品

スーベニアカップは「今回は買わない」として取り消し線付きで残しています。予定数は残る8種類・17個。未購入フィルターと残り個数は見送り品を除外し、以前カップに付けた購入チェックが残っていても集計しません。場所・買い方でも見送りと明記します。


## まとめて買えるレストラン

「場所」の先頭に、購入予定のスーベニアを2種類以上扱う共通店と対象品を掲載。店名からその店舗の地図を開けます。リストの飲食店グループと「買い方」からも移動でき、商品詳細・店舗一覧には共通店バッジが付きます。

2026年11月3日に公式の[タンブラー](https://www.tokyodisneyresort.jp/food/5063/)と[グミケース](https://www.tokyodisneyresort.jp/food/5061/)の販売店舗を照合。ザンビーニ、ハドソンリバー・ハーベスト、カスバ、セバスチャンの4店が共通です。見送り品は共通判定に含めず、購入済みになっても取扱店の案内は残します。店舗の判定は既存のITEMS.placesから導出します。
