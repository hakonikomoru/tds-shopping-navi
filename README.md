# シー買い物ナビ

2026年11月4日の東京ディズニーシーで買う予定の品を、買い方別・場所別にまとめたスマホ用の1ページです。

- 公開ページ: https://hakonikomoru.github.io/tds-shopping-navi/
- 販売場所・価格・画像は東京ディズニーリゾート公式サイト（2026年11月2日確認）より
- 外部ライブラリ依存なしの静的サイト。`index.html` をブラウザで開けばそのまま動きます

## 列とアプリの表示

商品カードと店舗一覧に、現地の待ち列・アプリ必要／任意／不要を表示。リストでは条件と購入済みを組み合わせて絞り込めます。待ち列は購入経路からの目安で、リアルタイム待ち時間ではありません。公式の販売条件は2026年11月2日確認、当日はアプリ・現地の最新案内を優先してください。

- ショップ3店: スタンバイパス。バッジ: アプリ限定配送。
- FSの3飲食店: モバイルオーダー。他の対象飲食店: アプリ任意。対象外店と掲載ワゴン: 店頭購入。
- 公式出典はサイトの「注意」タブに掲載。`GUIDANCE`、`PLACE_ACCESS`、`ACCESS` を更新して表示を保守します。
- 検証: `node tests/guidance.cjs`。HTMLの変更後はブラウザで絞り込み、購入済み保存、タブ・地図、狭い画面を確認します。

## 冬の装飾：ふんわりスノー

採用された「ふんわりスノー」の淡い水色・白を基調に、CSSの小さな雪だるま、雪の縁取り、SVGの雪の結晶を使用。装飾は静止表示で追加画像の通信なし。列・アプリの意味を表すバッジは従来の色分けを保ちます。装飾は読み上げ対象から除外しています。

## 店頭と配送の併売

チャーム・耐熱ガラスマグ・ファンキャップは、商品カード上に「店頭＋配送注文」と常時表示。「買い方」のアプリ欄にも一覧を掲載。フィギュアは店頭単品／配送BOXのみの違いを表示します。配送は入園後の公式アプリ注文で、ショップのパスは不要。予定数と購入済みチェックは購入方法にかかわらず共通です。


## 見送りの商品

スーベニアカップは「今回は買わない」として取り消し線付きで残しています。予定数は残る8種類・17個。未購入フィルターと残り個数は見送り品を除外し、以前カップに付けた購入チェックが残っていても集計しません。場所・買い方でも見送りと明記します。


## まとめて買えるレストラン

「リスト」の飲食店グループ・「買い方」・「場所」に、共通店と対象品をその場で開閉できるアコーディオンを掲載。開いてもタブは切り替わらず、同じ見出しで閉じられます。店名をタップすると各店の地図も一覧内で開きます。明示的な「この店の全メニューを見る」からはメニュータブへ移動できます。商品詳細・店舗一覧の共通店バッジも維持しています。

2026年11月3日に公式の[タンブラー](https://www.tokyodisneyresort.jp/food/5063/)と[グミケース](https://www.tokyodisneyresort.jp/food/5061/)の販売店舗を照合。ザンビーニ、ハドソンリバー・ハーベスト、カスバ、セバスチャンの4店が共通です。見送り品は共通判定に含めず、購入済みになっても取扱店の案内は残します。店舗の判定は既存のITEMS.placesから導出します。


## 飲食店の全メニュー

「メニュー」タブで掲載16店を切り替え、公式掲載の食事・デザート・飲み物・スーベニアを写真付きで表示。2026年11月3日取得で466件（店舗やカテゴリの重複を含む）、写真付き327件、画像170枚をローカル保存。写真なしのドリンク139件も掲載。写真をタップすると拡大できます。検索は店内の名前・カテゴリ・価格を対象に、全角／半角・ひらがな／カタカナを吸収します。「11/4の販売期間外を除く」は期間記載なしの品も含めます。期間内は在庫を保証しません。

「場所」の各飲食店と共通店一覧から直接その店のメニューへ移動できます。メニューから地図にも戻れます。既存の購入予定・チェックとは独立しており、カップは買い物リストでは見送りのまま、全メニューには公式掲載どおり残ります。

- 表示データ: `data/menus.js`。検索・期間判定: `menu-utils.js`。
- 取得記録: `data/menu-sources/2026-11-03.json`。公式URL・全カテゴリ・全価格・期間・DOM件数を保持。同名の別デザインや公式内の複数カテゴリ掲載を落としません。
- 画像台帳: `data/menu-sources/images-2026-11-03.json`（出典URL・ファイル名・SHA-256・取得時間）。実体: `img/menu/`。既存画像の加工・生成は行っていません。
- 再取得時は公式店舗のメニューページをブラウザで確認し、`scripts/extract-official-menu.js` の読み取り関数で収集。`.listTextArea > p` 全体を読むこと（`p.text` のみだとセット価格が欠落する）。画像も取得して新しい日付の記録を作り、旧版は保全します。
- `scripts/build-menus.cjs` の入力日付を合わせて `node scripts/build-menus.cjs`。`node tests/menus.cjs` と `node tests/guidance.cjs`、スマホ幅での画像・検索・店舗切替・購入チェックを確認します。
- 画像は遅延読み込み。ロード失敗でも商品名と価格、公式詳細リンクを残します。


## 商品名から公式へ

買い物リストの商品見出し、共通店・場所の対象品、買い方の商品名、全飲食メニューの商品名をリンク化。公式ページを別タブで開くため、元のナビの購入チェック・展開状態・スクロール位置を保持します。写真は引き続き拡大用です。個別ページがない139件の飲み物は各店の公式メニューへ案内します。見送りカップの名前も取り消し線のままリンクできます。

チャームのグループ名は公式のシリーズ商品一覧へ、3キャラクターの名前は個別商品へリンク。2026/11/3に公式一覧の画像とリンクを照合し、ダッフィー116002154、シェリーメイ116002155、リーナ・ベル116002160を確認しました。
